# Acceptance Tests

## 验收原则

只有满足本文件中的测试，才能认为第一版 MVP 完成。

“代码存在”不等于功能完成。

“界面可以打开”不等于项目完成。

最终验收必须使用打包后的应用，而不只是开发环境。

## 安装测试

### AT\-001：安装应用

前置条件：

- 一台没有安装项目开发环境的 macOS Apple Silicon 电脑

操作：

1. 打开 DMG 安装包

2. 将应用拖入 Applications

3. 启动应用

预期结果：

- 应用可以启动

- 不需要安装 Python

- 不需要安装 Node\.js

- 不需要手动安装 FFmpeg

- 不需要打开终端

- 不出现缺少动态库或模块的错误

## 项目创建测试

### AT\-002：创建新项目

操作：

1. 点击“新建项目”

2. 输入项目名称

3. 输入测试文案

4. 选择输出目录

5. 保存项目

预期结果：

- 项目创建成功

- 项目目录被创建

- `project.json` 被创建

- 原始文案被完整保存

- 关闭软件后可以重新打开项目

## 文案拆分测试

### AT\-003：拆分中文文案

输入：

```Plain Text
人工智能正在改变企业的工作方式。过去，许多工作需要员工手动完成。现在，自动化工具可以协助企业处理重复任务，提高工作效率。
```

预期结果：

- 文案被拆分为多个场景

- 每个场景有唯一编号

- 场景顺序与原文一致

- 没有文字丢失

- 没有重复文字

- 每个场景都有搜索关键词

## 图片搜索测试

### AT\-004：搜索场景图片

操作：

1. 对一个场景执行图片搜索

2. 等待搜索完成

预期结果：

- 返回至少一个候选结果，或显示明确的无结果信息

- 每个候选结果显示预览图

- 保存图片来源信息

- 用户可以选择其中一张图片

- 用户可以重新搜索

- 用户可以上传本地图片替换

### AT\-005：网络断开

操作：

1. 断开网络

2. 执行图片搜索

预期结果：

- 应用不崩溃

- 显示网络错误

- 提供重试按钮

- 已保存的项目不会丢失

## 语音生成测试

### AT\-006：生成中文语音

操作：

1. 输入中文场景文案

2. 选择中文语音

3. 点击生成语音

预期结果：

- 生成可播放的音频文件

- 语音内容与文案一致

- 音频没有明显截断

- 项目中记录音频路径

- 重复打开项目后音频仍然可用

### AT\-007：语音生成失败

模拟：

- 无效 API Key

- 请求超时

- 服务不可用

预期结果：

- 应用不崩溃

- 显示失败原因

- 用户可以重试

- 其他已经完成的场景不受影响

## 字幕测试

### AT\-008：生成字幕

操作：

1. 完成语音生成

2. 生成字幕

预期结果：

- 生成 SRT 文件

- 字幕顺序正确

- 字幕时间不重叠

- 字幕开始时间小于结束时间

- 最后一条字幕不超过音频结束时间

- 中文字符显示正常

### AT\-009：字幕画面测试

预期结果：

- 字幕位于画面安全区域

- 字幕不被画面边缘截断

- 字幕可以阅读

- 长字幕能够自动换行

- 竖屏和横屏均可以正常显示

## 视频生成测试

### AT\-010：生成竖屏视频

设置：

- 比例：9:16

- 测试场景：3 个

- 每个场景包含图片、语音和字幕

预期结果：

- 输出 MP4

- 视频可以正常打开

- 视频比例正确

- 视频包含全部场景

- 视频包含语音

- 视频包含字幕

- 音频与画面总时长基本一致

- 视频结束时没有长时间黑屏

### AT\-011：生成横屏视频

设置：

- 比例：16:9

预期结果：

- 输出 MP4

- 分辨率符合横屏设置

- 图片没有被异常拉伸

- 图片可以裁剪，但不能改变原始宽高比例

### AT\-012：取消生成

操作：

1. 开始生成视频

2. 在过程中点击取消

预期结果：

- 任务在合理步骤停止

- UI 恢复可操作状态

- 临时文件被清理或标记

- 项目文件没有损坏

- 用户可以重新开始生成

## 文件测试

### AT\-013：中文路径

输出目录示例：

```Plain Text
/Users/test/桌面/我的视频项目/
```

预期结果：

- 可以保存项目

- 可以下载图片

- 可以生成语音

- 可以输出视频

- 路径中的中文不会导致错误

### AT\-014：磁盘空间不足

预期结果：

- 生成前或生成过程中识别错误

- 显示磁盘空间不足

- 应用不崩溃

- 不生成损坏的最终视频

## 恢复测试

### AT\-015：应用意外关闭

操作：

1. 创建并保存项目

2. 在生成素材过程中关闭应用

3. 重新打开应用和项目

预期结果：

- 已保存文案仍然存在

- 已下载素材仍然存在

- 已生成音频仍然存在

- 未完成任务被标记为未完成

- 用户可以继续生成

## 完整端到端测试

### AT\-016：普通用户完整生成视频

测试人员：

- 没有编程经验

- 不使用终端

操作：

1. 安装应用

2. 新建项目

3. 粘贴 300 至 800 字中文文案

4. 使用默认设置

5. 选择图片

6. 生成视频

7. 打开输出文件

通过标准：

- 用户可以独立完成整个流程

- 最终 MP4 可以播放

- 视频包含图片、语音和字幕

- 软件没有崩溃

- 用户可以找到视频文件

- 不需要开发人员手动修复项目文件

## MVP 完成条件

以下条件全部满足，MVP 才算完成：

- 所有 P0 功能完成

- 自动化测试通过

- AT\-001 至 AT\-016 完成

- 打包后的应用通过测试

- README 提供安装说明

- 已知限制被记录

- 没有将 API Key 写入仓库

- 没有严重崩溃问题

- 可以输出真实 MP4 视频
